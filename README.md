# Phyo Thiha — Personal Website

The source for [phyothiha.com](https://phyothiha.com), a personal website introducing Phyo Thiha and showcasing selected background and projects. The site is published with GitHub Pages.

## Site contents

- `index.html` is the main portfolio page.
- `css/`, `js/`, `fonts/`, `img/`, and `files/` contain the site styles, scripts, fonts, images, and downloadable assets.
- `sites/` and `web_pages/` hold additional project and page content.
- `health/` is the public health page at [phyothiha.com/health/](https://phyothiha.com/health/). Its public summary data is refreshed by the home-server publisher maintained in [pthih/homelab](https://github.com/pthih/homelab).
- `sitemap.xml` lists the site's public pages.

## Changes and publishing

Make website changes on a branch and submit a pull request for review. Merging to the published branch updates the GitHub Pages site. The health summary data is generated by the home-server publisher; edit the publisher in `pthih/homelab` when its behavior needs to change.
